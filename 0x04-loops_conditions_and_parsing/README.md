# 0x04 - Loops, Conditions, and Parsing

This directory contains shell scripting exercises focused on fundamental programming constructs: loops, conditional statements, and text parsing. These exercises build upon basic shell knowledge to demonstrate how to iterate through data, make decisions based on conditions, and process text patterns.

## Learning Objectives

- Master different types of loops in bash: `for`, `while`, and `until`
- Understand conditional statements: `if`, `elif`, and `else`
- Learn text parsing and pattern matching techniques
- Combine loops and conditions to solve practical problems
- Process files and command output effectively

## Exercises

### Loop Exercises

- **1-for_best_school**: Demonstrates the `for` loop construct to iterate through a sequence
- **2-while_best_school**: Shows how to use `while` loops for conditional iteration
- **3-until_best_school**: Introduces `until` loops, which iterate until a condition becomes true
- **8-for_ls**: Applies `for` loops to iterate through file listings and directory contents

### Conditional Exercises

- **4-if_9_say_hi**: Uses `if` statements to evaluate conditions and control program flow
- **5-4_bad_luck_8_is_your_chance**: Combines conditions with `if/elif/else` statements
- **6-superstitious_numbers**: Demonstrates complex conditional logic with multiple branches

### File and Text Processing

- **9-to_file_or_not_to_file**: Teaches file testing and conditional operations on file existence

## Key Concepts

### Loops
- **for loops**: Iterate through lists of items, ranges, or file lists
- **while loops**: Execute commands repeatedly while a condition is true
- **until loops**: Execute commands repeatedly until a condition becomes true

### Conditional Statements
- **if/then/else**: Make decisions based on test conditions
- **elif**: Multiple conditions in sequence
- **Test operators**: `-eq`, `-ne`, `-lt`, `-gt`, `-e`, `-f`, `-d`, etc.

### Parsing
- Extract and process information from text and command output
- Use pattern matching and filtering techniques
- Work with file system data

```bash
bash ./3-until_best_school

```
